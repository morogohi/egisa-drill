# 전기기사 실기 · 단답 드릴

2004~2025년 전기기사 실기 기출 22개년(954페이지) 분석 기반, 단답형 100문항 암기 학습 웹앱입니다.
서버 없이 동작하는 단일 `index.html` 정적 페이지로, GitHub Pages에 바로 배포할 수 있습니다.

## 기능

- **학습** — 플래시카드 모드(보고 채점) / 답안 작성 모드(직접 입력 후 모범답안 대조). 범위·대상(전체/미학습/오답만/약점 우선)·순서·문항 수 설정, 키보드 조작(Space, 1/2/3, Esc)
- **암기장** — 문제·답 열람, 장별 필터, 키워드 검색, 답 전체 펼치기/가리기
- **오답노트** — 틀림·부분 문항 자동 수집, 문항별 메모, 작성 모드에서 내가 쓴 답 보관, 재정답 시 자동 해제
- **기록** — 누적 정답률, 안정권 문항 수, 11개 장별 진행률, 세션 이력, 전체 초기화

## 데이터 저장

학습 기록은 브라우저 `localStorage`에 저장됩니다 (키: `egisa-dan-drill-v1`).
서버로 전송되는 데이터는 없으며, 같은 브라우저에서 다시 열면 기록이 유지됩니다.
브라우저나 기기를 바꾸면 기록은 공유되지 않습니다.

## GitHub Pages 배포 방법

1. GitHub에서 새 저장소(repository)를 만듭니다. 예: `egisa-drill` (Public)
2. 이 폴더의 `index.html`과 `README.md`를 저장소에 업로드합니다.
   - 웹에서: 저장소 → **Add file → Upload files** 에 드래그 앤 드롭 → Commit
3. 저장소 **Settings → Pages** 로 이동합니다.
4. *Build and deployment* 에서 Source를 **Deploy from a branch**, Branch를 **main / (root)** 로 선택하고 저장합니다.
5. 1~2분 후 `https://<계정명>.github.io/<저장소명>/` 에서 접속할 수 있습니다.
