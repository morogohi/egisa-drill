## 학습 로드맵

7월 20일부터 시험 당일까지 98일을 4개 구간으로 나눈 일정 관리 도구입니다.

- **구간 A (7/20–8/24)** 건축전기설비기술사 필기 주력, 주말만 기사 KEC 15회분
- **구간 B (8/25–9/28)** 기사 실기 전력질주, 2004~2020년 51회분 + 요약집 제작
- **구간 C (9/29–10/9)** 산티아고 순례, TTS 청취와 오답노트만
- **구간 D (10/10–10/25)** 감각 복원 후 마무리

기능: 오늘 할 일 카드, 전체 98일 열람, 항목별 체크, 구간·유형별 진도율,
JSON 내보내기·복원. 기출 66회분(2004~2025)이 날짜에 빠짐없이 배정되어 있습니다.

저장 키: `egisa-roadmap-v1`

## 단답형 드릴

2004~2025년 22개년(954페이지) 기출 분석 기반 단답형 100문항 암기 앱입니다.

- **학습** — 플래시카드 모드 / 답안 작성 모드. 범위·대상(전체·미학습·오답만·약점 우선)·순서·문항 수 설정, 키보드 조작(Space, 1/2/3, Esc)
- **암기장** — 문제·답 열람, 장별 필터, 키워드 검색
- **오답노트** — 틀림·부분 문항 자동 수집, 문항별 메모, 재정답 시 자동 해제
- **듣기** — TTS 연속 재생, 백그라운드·잠금화면 재생(MediaSession), 화면 꺼짐 방지
- **기록** — 누적 정답률, 11개 장별 진행률, 세션 이력

저장 키: `egisa-dan-drill-v1`

## 데이터 저장

기록은 브라우저 `localStorage`에만 저장되며 서버로 전송되지 않습니다.
두 도구는 저장 키가 달라 서로 간섭하지 않습니다.
브라우저나 기기를 바꾸면 기록이 공유되지 않으므로,
장기 외출 전에는 각 도구의 내보내기 기능으로 백업해 두세요.

## 배포

```bash
./deploy.sh
```

저장소를 클론해 파일을 교체하고 푸시합니다. 구버전 잔여 파일(`index_2.html` 등)도 함께 정리합니다.

수동 배포 시에는 아래 구조 그대로 업로드하세요.

```
index.html
drill/index.html
roadmap/index.html
.nojekyll
README.md
```

**GitHub Pages 설정**: Settings → Pages → Source를 *Deploy from a branch*,
Branch를 *main / (root)* 로 지정합니다.

### 배포 확인

`raw.githubusercontent.com`은 CDN 캐시 때문에 옛 내용을 반환할 수 있습니다.
저장소의 실제 상태는 아래로 확인하세요.

```bash
curl -sL https://codeload.github.com/morogohi/egisa-drill/tar.gz/refs/heads/main | tar tz
```
